# Your checklist for M2 (about 15 minutes)

M2 replaces "unzip a folder and double-click" with a proper installer, an icon beside the clock, and updates that install themselves.

Your library, sign-in and watch history are kept. They live in a separate folder that the installer never touches.

## 1. Install

1. Close the old program if it is running (close its black window).
2. Download **LocalMedia-Setup.exe** from the link I give you and double-click it.
3. Windows will probably show the blue "Windows protected your PC" box again, because the installer is not signed yet: **More info**, then **Run anyway**.
4. Leave both boxes ticked: "Start Local Media when I sign in" and "Let other devices at home connect".
5. Windows asks once for permission, to add the firewall rule. Say **Yes**. This replaces the firewall question from before.
6. Finish. Local Media starts by itself.

## 2. Check it carried on where you left off

1. Your browser opens. You should still be signed in, with the same library and the same "Continue watching".
2. Look beside the clock (you may need the small arrow to show hidden icons): there is a dark square with a blue triangle. Right-click it. You should see Open, Start with Windows, Check for updates and Quit.
3. There is no black window any more. That is expected.

## 3. Restart test

1. Restart the PC and sign in.
2. Without starting anything, open Local Media on your iPhone. It should already be running.

## 4. Updates

1. In the app, click **Settings** and find the **Updates** box.
2. It shows your version. "Look for a newer version" should say you have the newest, or say plainly that no published version was found.
3. When I publish the next version you should not have to do anything: it installs itself when nobody is watching. I will tell you when one is out so you can confirm it arrived.
