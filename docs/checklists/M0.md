# Your checklist for M0 (about 15 minutes)

M0 is the first build that proves the idea. It finds video files in one folder and plays the ones a browser can play by itself. **Expect many of your files not to play yet, or to play with no sound.** That is normal until M3.

Your files are only read. Nothing in your folders is changed.

## 1. Get the program

1. Open the release page I link to in the chat (you must be signed in to GitHub while the project is private).
2. Download `localmedia-windows-amd64.zip`.
3. Right-click the zip, choose "Extract All", and open the folder it makes.

## 2. Start it

1. Double-click `localmedia.exe`.
2. Windows will probably show a blue box, "Windows protected your PC". That is because the program is not signed yet. Click **More info**, then **Run anyway**.
   - If there is no "Run anyway" button, stop here and tell me. Your PC has a stricter setting (Smart App Control) and we need to deal with that first.
3. A black window opens and stays open. That window is the program; closing it stops Local Media.
4. Windows may ask whether to allow the program on your network. Tick **Private networks** and click **Allow**.
5. Your browser opens the setup page by itself. If it does not, open `http://localhost:8177`.

## 3. Set it up

1. Choose a user name and a password (at least 8 characters). They live only on this PC.
2. Click through to the folder that holds your videos, then click **Finish setup**.
3. You should see a list of your video files.

## 4. Open it on your iPhone

1. On the PC, click **Open on another device**. A square code and an address appear.
2. On the iPhone, connected to the same Wi-Fi, point the camera at the code and tap the link. Sign in with the same user name and password.
3. If the iPhone cannot connect: on the PC open Settings → Network & internet → Wi-Fi → your network, and set it to **Private network**. Then try again.
4. Optional: in Safari tap the Share button, then **Add to Home Screen**, to give Local Media its own icon.

## 5. Try playing

1. On the PC and on the iPhone, play one `.mp4` file. Skip ahead, go back to the list, and open the file again: it should carry on where you stopped.
2. Try two or three other files. Some will not play, or will have no sound, and the page will say so. That is expected.

## 6. Send me the results

1. On the PC, click **Export support bundle**. It saves one small zip file. It holds the program version, how many files of each type you have, the names of files that failed to play, and recent log lines with network addresses removed. No video, no passwords.
2. Attach that file to our chat. Do not post it on GitHub.
3. Tell me in a sentence or two: did the Windows warnings appear as described, did the iPhone connect, did the `.mp4` play on both, and did it resume?
