The first published version (milestone M3: plays most things).

**What it does**

- One program on a PC. Pick the folders your films and shows are in, and watch them in a browser on the PC or on any other device at home, including an iPhone. It remembers where you stopped, on every device.
- It keeps a library: films and shows with posters and descriptions, "continue watching", "next up", and search.
- A file your device cannot play as it is gets repackaged while you watch, and its sound converted if need be. That covers most `.mkv` files on an iPhone, Dolby or DTS sound in Chrome, and TV recordings (`.ts` files). The picture is never changed, so nothing is lost in quality.
- You can pick the sound track and subtitles under the player. Your choice is remembered for the show, and each person has their own language preferences.
- On Windows it installs like any other program, sits beside the clock, starts with Windows if you want, and **updates itself**: it backs up first, and goes back by itself if a new version does not start.

**What it does not do yet**

- Files whose *picture* is in a format your device cannot show do not play yet. They are marked in the list. That is the next milestone.
- Subtitles stored as pictures (as on discs) and styled subtitles are not shown yet; plain text ones are.
- No apps for phones or TVs yet: everything runs in the browser.

**Which file to download**

- Windows: **LocalMedia-Setup.exe**. Run it; it installs over any earlier copy and keeps your library and watch history.
- Mac: `localmedia-darwin-arm64.zip` (Apple chips) or `localmedia-darwin-amd64.zip` (Intel). Linux: `localmedia-linux-amd64.zip` or `localmedia-linux-arm64.zip`. These need `ffmpeg` and `ffprobe` installed separately; the Windows installer includes them.

The installer is not signed yet, so Windows shows a blue warning the first time: **More info**, then **Run anyway**.

If you installed a build from a test link before: install this one once by hand. From then on new versions arrive by themselves.
