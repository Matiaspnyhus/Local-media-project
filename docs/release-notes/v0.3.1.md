The second published version: repairs to the first one, and one new thing for laptops.

**New**

- **The PC stays awake while someone is watching.** Windows does not count sending a film to a phone as "the PC is being used", so a laptop left alone could fall asleep in the middle of a film. While a film is playing (and for five minutes after, so that a short pause is fine), Local Media now asks Windows not to go to sleep. It never keeps the screen on and changes none of your settings. Two things it cannot do: closing the lid still puts a laptop to sleep unless you change that in Windows (the checklist shows where), and on battery Windows may still put a laptop to sleep after a few minutes, so keep it plugged in.

**Repaired**

- **An update no longer interrupts a film.** A new version used to be able to restart the app while someone was watching. Now it waits for a quiet moment, and **Settings** says that it is waiting and for whom. **Install it now** tells you who is watching before it goes ahead.
- **Subtitle files saved by older Windows programs keep all their lines.** Subtitle files beside a film (`.ass`, `.ssa`, `.sub`, and `.srt` files with stray characters) lost every line that had a letter such as æ, ø or å, or showed them wrongly.
- **A film kept as two files** (for example a full HD copy and a 4K copy) is now judged and played from the same copy, the one your device plays most easily. Before, the list could say "plays" for a film that then refused to start. If one of the two files has been deleted, the other one plays.
- **A clip that was trimmed without re-encoding** resumes at the right place on every device, and is no longer restarted from the beginning when you stop it a few seconds before its end.
- **Installing over a running copy, and uninstalling,** no longer fail because the converter is still busy with a film.
- **After a crash or a forced shutdown,** the temporary files that were left behind are cleared at the next start.

**Known and not yet fixed**

- A file whose key frames are very far apart (some screen recordings and camera files) may not play when it has to be repackaged.
- As in the first version: files whose *picture* is in a format your device cannot show do not play yet, subtitles stored as pictures and styled subtitles are not shown yet, and there are no apps for phones or TVs yet.

**Which file to download**

- Windows: **LocalMedia-Setup.exe**. Run it; it installs over any earlier copy and keeps your library and watch history.
- Mac: `localmedia-darwin-arm64.zip` (Apple chips) or `localmedia-darwin-amd64.zip` (Intel). Linux: `localmedia-linux-amd64.zip` or `localmedia-linux-arm64.zip`. These need `ffmpeg` and `ffprobe` installed separately; the Windows installer includes them.

The installer is not signed yet, so Windows shows a blue warning the first time: **More info**, then **Run anyway**.

If you have version 0.3.0 installed, this one arrives by itself (look under **Settings**, **Updates**). If you have an older test build, install this one once by hand; from then on new versions arrive by themselves.
