First playable build (milestone M0). For testing only.

**What it does:** one program. Set it up on the PC, pick a folder, and play video files in a browser on the PC or on another device at home. It remembers where you stopped.

**What it does not do yet:** it plays only files a browser can play by itself, typically `.mp4`. Many other files will not play or will have no sound, and the page says so. That is expected until a later version.

**Which file to download:** `localmedia-windows-amd64.zip` for a normal Windows PC. Mac: `darwin-arm64` (Apple chips) or `darwin-amd64` (Intel). Linux: `linux-amd64` or `linux-arm64`.

The program is not signed yet, so Windows shows a warning the first time. The checklist in `docs/checklists/M0.md` says what to click.
